## Como colocar no GitHub

1. Extraia o ZIP no computador. Abra a pasta `Exercicios_ML_UDF`.
2. Crie um repositório na sua conta, com nome como `aprendizado-maquina-udf`. Escolha a visibilidade de acordo com a orientação da professora.
3. No repositório, use **Add file > Upload files**. Envie o conteúdo da pasta, incluindo as subpastas. O `README.md` deve ficar na raiz do repositório.
4. Registre um commit, por exemplo `Adiciona modelos das atividades do módulo IV`.
5. Abra cada `.md`, clique no lápis de edição, preencha os campos e confira a prévia. Registre um commit que descreva o exercício realizado.
6. No Colab, abra o notebook, execute as células na ordem e acrescente suas interpretações em células Markdown. Baixe o `.ipynb` e envie para `notebooks/laboratorio-equipe.ipynb`.
7. Se usar Orange, envie o fluxo `.ows` e imagens de resultados, e preencha o relatório da atividade 03. Informe o caminho real dos arquivos.
8. Atualize os links das evidências, confira se abrem no GitHub e envie o endereço do repositório no ambiente indicado pela professora.

Se preferir criar arquivos diretamente no GitHub, use **Add file > Create new file** e escreva um caminho como `notebooks/registro.md`. O nome com barra cria a pasta junto com o arquivo.

## Convenções de registro

- Substitua **PREENCHER** pelo seu registro. Use “não se aplica” com justificativa quando necessário.
- Mantenha o enunciado e acrescente as respostas nos espaços indicados.
- Distinga **resultado calculado**, **interpretação** e **hipótese**.
- Mostre valores realmente executados. Informe versões, semente, divisão dos dados e configurações.
- Não envie matrículas, telefones, credenciais nem dados pessoais reais. Use apenas o conjunto sintético desta prática.
- Referencie fontes adicionais consultadas e declare como utilizou ferramentas de IA, se houver, mantendo responsabilidade pelo conteúdo.
